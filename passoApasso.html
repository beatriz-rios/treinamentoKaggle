Treinamento de IA no Kaggle

Passo a Passo com Roboflow e YOLOv8

Clique em "Próximo" para começar o tutorial interativo.

Passo 0: Preparação Crucial do Kaggle

Antes de rodar qualquer código, precisamos garantir que o Kaggle tenha poder de processamento e acesso à internet (para evitar o erro "Temporary failure in name resolution").

  • 1. Ative a GPU: No menu lateral direito, vá em Notebook options > Accelerator e escolha uma GPU (ex: GPU T4 x2).
  • 2. Ligue a Internet: No mesmo menu, ative a chave Internet. (Nota: pode ser necessário verificar seu celular na conta do Kaggle para liberar isso).

Passo 1: Instalar o Ultralytics

O Ultralytics é a biblioteca oficial que contém os algoritmos do YOLOv8. Crie uma célula de código no Kaggle e insira o comando abaixo:

!pip install ultralytics
💡 Dica: O sinal de exclamação (!) antes do pip é necessário no Kaggle para avisar que este é um comando de instalação do sistema, e não um código Python normal.

Clique no botão de "Play" ao lado da célula e aguarde a instalação terminar (os textos devem rodar sem erros vermelhos ou amarelos agora que a internet está ligada).

Passo 2: Importar o Dataset do Roboflow

Agora vamos instalar a biblioteca do Roboflow e baixar o seu projeto específico de Equipamentos de Proteção Individual (EPI). Em uma nova célula, cole este código e rode:

!pip install roboflow

from roboflow import Roboflow
rf = Roboflow(api_key="SUA_CHAVE_DE_API")
project = rf.workspace("NOME_DA_WORKSPACE").project("NOME_DO_PROJETO")
version = project.version(NUMERO_DA_VERSAO_DO_PROJETO)
dataset = version.download("yolov8")
⚠️ Aviso de Segurança: Sua api_key funciona como uma senha. Como este notebook é para você, não há problema, mas evite compartilhar notebooks públicos contendo essa chave visível.

Passo 3: Iniciar o Treinamento da IA

Finalmente, na terceira célula, vamos iniciar o treinamento. Note que usamos dataset.location para evitar o erro de "arquivo não encontrado" que tivemos antes!

# Inicia o treinamento
from ultralytics import YOLO

# Carrega um modelo pré-treinado leve (n = nano)
model = YOLO('yolov8n.pt') 

# Usamos f"{dataset.location}/data.yaml" para encontrar a pasta exata automaticamente
results = model.train(data=f"{dataset.location}/data.yaml", epochs=300, imgsz=640)
  • epochs=300 A IA vai estudar suas imagens 300 vezes.
  • imgsz=640 As imagens serão redimensionadas para 640x640 pixels durante o treino.

Passo 4: Acessar os Arquivos e Resultados

O YOLO salva automaticamente o "cérebro" da sua IA e vários gráficos de desempenho enquanto treina. Você pode ver e baixar isso diretamente no Kaggle!

Como encontrar seu modelo treinado:

  • Olhe para o painel lateral direito (o mesmo onde você ligou a internet).
  • Role para baixo até encontrar a aba Output e clique na setinha para expandir a pasta /kaggle/working.
  • Siga este caminho de pastas: runs ➔ detect ➔ train (pode estar como train2, train3, caso tenha rodado mais de uma vez).
  • Abra a pasta weights. Lá dentro você encontrará o arquivo best.pt. Você pode clicar nos três pontinhos ao lado dele para baixar o seu modelo final!

🎉 Tudo Pronto!

Agora é só esperar! O treinamento de 300 épocas (epochs) pode demorar alguns minutos ou horas, dependendo do tamanho do seu dataset.

Ao final, os resultados e o arquivo final da sua IA treinada (chamado best.pt) estarão salvos na pasta /kaggle/working/runs/detect/train/weights/.

Bom treinamento!
